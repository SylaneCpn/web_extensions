# web_entensions dart package

A simple tool to help build web entension in dart.

## Get sarted

Add `web_extensions` to your `pubspec.yaml` :

```yaml
dev_dependencies:
 web_extensions:
    git: https://github.com/sylanecpn/web_extensions.git
```

Then use the tool :

```bash

dart run web_extension build

```

See usage with :

```bash

dart run web_extensions build --help

```

## Exemple usage

```bash

dart run web_extensions build -s ./sourceDir -d ./destDir -v

```
